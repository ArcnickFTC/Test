Releon Minecraft 1.21.11 Fabric Client - Build Instructions

Requirements:
- JDK 21
- Internet connection on first build (Gradle and Fabric/Minecraft dependencies must be downloaded)

Windows:
1. Extract this folder.
2. Open a terminal in the project folder.
3. Run: gradlew.bat build
4. The built mod JAR will be in: build\libs\

macOS/Linux:
1. Extract this folder.
2. Open a terminal in the project folder.
3. Run: chmod +x gradlew
4. Run: ./gradlew build
5. The built mod JAR will be in: build/libs/

The project targets Minecraft 1.21.11, Fabric, and Java 21.
